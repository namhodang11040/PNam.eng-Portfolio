Creative Automation Project

Art Sand Table

Designed and built a custom sand table using magnetic actuation, stepper motors, Arduino, and ESP32. The system moves a steel ball beneath the surface to create dynamic patterns in sand.

Arduino ESP32 Stepper Motor Polar Coordinate

Challenge

  • • Non-Cartesian movement system
  • • Coordinate conversion complexity
  • • Accurate magnetic positioning

Result

  • • Stable motion control
  • • Smooth pattern generation
  • • Successful polar coordinate implementation
Technical Challenges
  • • Implementing movement using radius (X) and angular rotation (α) instead of traditional X/Y Cartesian axes.
  • • Synchronizing dual stepper motors for smooth and accurate motion.
  • • Designing reliable homing logic using a single sensor.

Industrial Improvement Project

Shrink Packaging Machine Upgrade

Redesigned and reprogrammed a shrink packaging machine to improve safety, production speed, and operational flexibility for factory products.

Mitsubishi PLC HMI Sensor Logic Industrial Troubleshooting

Before

  • • Blade cutting product errors

After
